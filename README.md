# Restaurant Management System

A Java console application demonstrating object-oriented programming through a restaurant workflow.

## Features
- Menu item management
- Employee management
- Employee roles (Waiter, Chef and Manager)
- Order creation and order history
- Billing and receipt generation
- File-based storage for menu, employees and orders

## OOP concepts demonstrated
Classes and objects, inheritance, encapsulation, polymorphism/interfaces and file handling.

## Requirements
- JDK 8 or later

## Compile
```bash
javac *.java
```

## Run
```bash
java Main
```

If your local Java setup uses a different entry-point class, inspect `Main.java` and run the class that invokes `RestaurantSystem.start()`.

## Notes
The `.class` files are generated build output and are not included. Compile from this folder so the text data files are available to the application.
